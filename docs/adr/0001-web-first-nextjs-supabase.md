# Web-first Next.js and Supabase stack

We will build PropTrack v1 as a full-stack Next.js web app hosted on Vercel, backed by Supabase Auth, Postgres, and Storage. We chose this over native Android first or Firebase because the v1 product is report-heavy, form-heavy, and relational, while mobile-specific features such as push notifications and calendar integration are deferred to a later React Native app.
